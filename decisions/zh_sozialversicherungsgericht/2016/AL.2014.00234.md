# Keine belegten Schritte zur Realsierung ausstehender Lohnansprüche, insbersondere keine Einleitung rechtlicher Schritte über eine längere Zeit, obschon Lohnausstände in grossem Umfang aufgelaufen waren. Daher kein Anspruch auf eine Insolvenzentschädigung.
