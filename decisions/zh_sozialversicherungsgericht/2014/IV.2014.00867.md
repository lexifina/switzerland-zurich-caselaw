# Eine Rente für einen späteren Zeitraum kann nicht endgültig festgelegt werden, solange sie für den vorangehenden Zeitraum nicht rechtskräftig beurteilt worden ist. Eine neue Rentenverfügung, die während des hängigen Prozesses gegen eine Rentenverfügung erlassen wird, gilt deshalb grundsätzlich als mitangefochten.
