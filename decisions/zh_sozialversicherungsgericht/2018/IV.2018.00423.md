# Offensichtlich unbegründete Beschwerde: Neuanmeldung kurz vor Pensionierung, sodass ein Anspruch auf eine Invalidenrente bei Bezug einer AHV-Rente nicht mehr entstehen konnte. Eingliederungsmassnahmen für einen Monat erweisen sich als zweckwidrig. Antrag auf Durchführung einer öffentlichen Verhandlung ist schikanös und wird abgewiesen.
